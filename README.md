An interactive, cozy, early-web portfolio built for **Pip the Skull Baby** during the **haX.baby "Baby's First Website" 48-Hour Hackathon** (Oct 17–19, 2026).

---

## 🏆 Hackathon Rubric & Feature Map
This project was engineered to maximize the official judging rubric:

* **35% Functionality & Polish:** Zero console errors, fully managed React state, accessible keyboard navigation (`tabIndex` & focus rings), and persistent `localStorage` for the guestbook and odometer.
* **30% Early-Web Soul:** Features a retro Hit Counter Odometer, a Sparkle Cursor Trail, and a custom "Chaos Mode" that applies CSS rotations and marquee effects to the DOM.
* **20% Creativity & Surprises:** A hidden Easter Egg (boop Pip's pink bow 3 times!), an interactive Web Audio API music box, and a playable SVG rooftop glider mini-game.
* **15% Clean Craft:** 100% mobile-responsive (tested down to 360px). Unified glassmorphism navigation bar with 44px minimum touch targets.

## 🛠️ The Sandbox (Tech Stack)
* **Framework:** React 19 + Vite
* **Styling:** Tailwind CSS v4 (Custom early-web color tokens: Cream, Berry, Cocoa, Midnight, Amber)
* **Motion & Interactions:** Framer Motion, Canvas-Confetti
* **Audio Engine:** Zero-dependency Native Browser `AudioContext`
* **Icons & Fonts:** Lucide React, Google Fonts (Fraunces & Fredoka)
